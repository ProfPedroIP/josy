# 🕹️ Josy Arcade

Um projeto de fliperama em pixel-art feito com muito carinho e dedicação, desenhado especialmente para a Josy! 👾💖

O **Josy Arcade** evoluiu bastante desde a sua concepção original. O que começou como uma simples ideia tomou forma e se transformou em uma experiência completa, reunindo elementos nostálgicos de arcade, efeitos sonoros customizados e referências pensadas sob medida.

## 🚀 Destaques do Projeto
* **Design Customizado:** Ícones criados exclusivamente para a aplicação (`icon-192.png` e `icon-512.png`).
* **Experiência Sonora Imersiva:** Integração de efeitos sonoros originais (`click.aac`, `cool.aac`, `excited.aac`) para tornar a gameplay interativa e divertida.
* **Easter Eggs & Temas Especiais:** Inclui referências temáticas divertidas, como a "Guerra Estelar".
* **Hospedagem na Nuvem:** Estruturado e configurado para deploy rápido e eficiente utilizando o **Firebase**.

## 🛠️ Tecnologias e Estrutura
* **Linguagens:** HTML5, CSS3, JavaScript (Stack Web Padrão)
* **Deploy e Hosting:** Firebase (configurado via `.firebaserc`)
* **Assets:** Gerenciamento organizado de mídias e controle de versionamento limpo (com `.gitignore`).
